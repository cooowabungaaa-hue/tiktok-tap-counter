Setup Guide 🚀

1. Download & Extract

Click the download button above to get the zip file. Extract (unzip) the contents to a folder on your computer (e.g., Desktop or Documents).

2. Run the Application

Double-click TikTokTapCounter.exe inside the extracted folder. A black window (console) will open - keep this open!

3. Connect to Stream

Your browser should automatically open to the dashboard. If not, go to http://localhost:8000.

Enter your TikTok username (the @handle) and click Connect.

4. Updates

When a new version is released, you'll see a notification in the app. Just click Update and let the tool handle the rest!

Troubleshooting

  • "Windows protected your PC" popup?
    Click "More info" -> "Run anyway". This happens because the app isn't signed with a costly certificate yet.
  • Port 8000 error?
    Make sure no other version of the tool is running. Check Task Manager to close old processes.
